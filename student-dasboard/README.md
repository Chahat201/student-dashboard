# Student Dashboard 🚀

A full-stack student dashboard built using **Next.js** and **Supabase**.

## 🔥 Tech Stack
- Next.js (App Router)
- TypeScript
- Supabase (Database + Auth)
- Tailwind CSS

## 📌 Features
- Student dashboard UI
- Database integration with Supabase
- Fast and responsive design
- Modern Next.js architecture

## 🚀 Getting Started

```bash
npm install
npm run dev
